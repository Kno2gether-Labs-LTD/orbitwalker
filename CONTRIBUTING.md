# Contributing to OrbitWalker

Thank you for wanting to help!

**Pull requests aren't being accepted yet.** OrbitWalker is still being set up, and there isn't enough maintainer time to review contributions properly. Contributions will open soon; this page will say so when they do.

## What helps right now
- **Feedback and device reports.** Open an issue using the *Feedback / device report* template: which glasses, which phone and Android version, what worked, and what didn't.
- **Logs.** In the app, Settings → **Share logs**. They contain device and connection details, never what you typed or the text of your notifications.
- **Ideas.** Tell us what would make OrbitWalker your daily setup.

## Security problems
Please don't open a public issue. See [SECURITY.md](SECURITY.md).
